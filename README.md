## Winux - Cross-platform Tooling

TL;DR:
Winux makes cross-platform apps way easier to maintain, it ensures you get to work on your app without worrying about what platform the app will run on, with a nice and smooth API

1. Why Winux?

Winux is made to be lightweight and small, easily embeddable without taking much space, while giving you feature's that you would use in a general app without becoming bloated.

2. What Does Winux Offer?

As of now, Winux offer's a variety of tools to work with from process, file system and much more.
Winux will receive even more features, while staying lightweight and easy to use in an app.

3. Can I Use It For Commercial?

Yes, Winux ensures you will have a smooth experience with licensing and without worries. It uses a permissive MIT license.
